# EduNexus

Full-stack college academic records platform.

## Stack
- Frontend: React, Vite, Tailwind CSS, React Router, Axios
- Backend: Java 21, Spring Boot 4.0.x, Spring Data JPA, Spring Security (JWT)
- Database: PostgreSQL
- Roles: STUDENT, HOD, ADMIN

## Structure
- `backend/`  - Spring Boot REST API
- `frontend/` - React app

## Run the backend
    cd backend
    .\mvnw.cmd spring-boot:run
